# MVP-4（手順メタデータ・高度化）

- `requiredActions`の編集UI（順序入替、名前変更）
- スキーマバージョニング対応

## 概要
VR側でのゲーティング（進行制御）に必要な「必須手順（Required Actions）」をエディタ側で定義・編集できるようにするフェーズ。
また、将来的な仕様変更に耐えうるバージョン管理機能を強化する。

## 実装項目
### 1. 手順データ編集UI
- [ ] `requiredActions`リストの表示
- [ ] アクションの追加・削除・名称変更
- [ ] ドラッグ＆ドロップ（または上下ボタン）による順序入れ替え
- [ ] 各アクションのID管理

### 2. スキーマバージョニング
- [ ] JSONの`version`フィールドを活用した読み込み分岐
- [ ] 旧バージョンのファイル読み込み時の自動アップグレード処理（必要に応じて）
- [ ] 将来的な拡張フィールドへの対応準備
