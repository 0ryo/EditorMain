# MVP-2（入出力・妥当性）

- JSONエクスポート/インポート（定義済みスキーマ準拠）
- 簡易Validation（必須要素チェック）

## 概要
MVP-1で作成した配置データを、外部ファイル（JSON）として保存・読み込み可能にするフェーズ。
また、出力時に「車両がない」「タイヤがない」などの矛盾を検知する簡易バリデーションを実装する。

## 実装項目
### 1. JSONエクスポート
- [ ] シーン内の`PlacedObject`を走査
- [ ] JSON構造（`version`, `meta`, `objects`）を構築
- [ ] `Newtonsoft.Json`でシリアライズしてファイル書き出し

### 2. JSONインポート
- [ ] JSONファイルを読み込みデシリアライズ
- [ ] 既存オブジェクトをクリア（または新規シーン）
- [ ] `objects`リストからPrefabをInstantiateし、Transformを適用

### 3. Validation（妥当性チェック）
- [ ] エクスポート実行時にチェック処理を挟む
- [ ] 必須チェック：車両（Target）が1つ以上あるか
- [ ] 必須チェック：交換用タイヤなどが配置されているか
- [ ] 警告表示：エラーがある場合は保存前に警告ダイアログを出す
