# MVP-3（使い勝手・UX向上）

- インスペクタ（Transform数値、`params`編集）
- スクリーンショット出力、ヘルプツアー

## 概要
基本機能（MVP-1, 2）に加え、より詳細な編集機能とユーザー補助機能を追加するフェーズ。
オブジェクトのプロパティ編集や、コースのプレビュー画像生成などを実装する。

## 実装項目
### 1. インスペクタ実装
- [ ] 選択されたオブジェクトのTransform（位置・回転）を数値入力で修正可能にする
- [ ] `params`（任意パラメータ）の編集UI実装
    - 例：車両の対象ホイール位置、タイヤサイズなど

### 2. スクリーンショット出力
- [ ] コース全体を収めるカメラ視点からのキャプチャ機能
- [ ] 保存時にサムネイル画像としてJSONと共に（または参照として）保存

### 3. ヘルプ・チュートリアル
- [ ] 初回起動時またはヘルプボタンでの操作ガイド表示（ツアー形式）
- [ ] キー操作一覧の表示改善
