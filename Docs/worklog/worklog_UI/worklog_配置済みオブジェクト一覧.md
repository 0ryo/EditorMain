# 配置済みオブジェクト一覧仕様

## 1. 目的

- 3Dビューに配置済みのオブジェクトを名前・ID・typeIdから検索する。
- 一覧から選択、表示/非表示、編集固定/解除を操作する。
- 通常時の3Dビューを狭めないため、初期状態では「一覧」ボタンだけを表示する。

## 2. 表示と配置

- `EditModeRow` の下に `Button_Outliner` を配置する。
- ボタンを押すと `Panel_Outliner` を開き、閉じるボタンまたは同じ一覧ボタンで閉じる。
- Panelは下部のシナリオ領域を避け、利用できる3Dビューの高さに合わせる。
- 3Dビュー上の他の操作ボタンと同じ角丸・hoverガイドを適用する。

## 3. 操作

- 検索: 表示名、オブジェクトID、typeIdの部分一致。
- 選択: 非表示でも固定でもないオブジェクトを選択する。
- 非表示: Rendererだけを無効化し、シナリオ参照やexport対象からは除外しない。非表示中はColliderも無効化して3Dビューから選択できないようにする。
- 固定: Colliderを無効化して3Dビューから選択・移動できないようにする。一覧から解除できる。
- 選択中のオブジェクトを非表示または固定にした場合は選択を解除する。
- 固定または非表示のオブジェクトを複製した場合、複製先は表示・固定解除状態にする。

## 4. 更新契機

- 配置、Undo/Redo、選択、表示名変更で一覧を更新する。
- Panelを開いている間は、外部操作による構成変更も定期的に検知する。
