# 数値Transform仕様

## 1. 表示

- オブジェクト選択時、右側の詳細パネルへ `Transform` セクションを表示する。
- 位置・回転・スケールをX/Y/Zの数値で表示し、入力確定時に反映する。
- ギズモ操作などで値が変化した場合も数値表示を追従させる。

## 2. 座標系

- `座標: 世界` / `座標: ローカル` ボタンで表示・入力する座標系を切り替える。
- 世界座標ではworld position、world rotation、lossy scaleを扱う。
- ローカル座標ではlocal position、local rotation、local scaleを扱う。
- 座標系は移動・回転ギズモの軸方向にも反映する。

## 3. 基準点

- `基準: 中心` / `基準: ピボット` ボタンでギズモの基準点を切り替える。
- 中心はRenderer境界の中心、ピボットはTransform positionを使用する。
- 中心基準のスケールでは境界中心を維持するよう位置も補正する。

## 4. Undo / Redo

- 数値入力による位置・回転・スケール変更はCommand履歴へ記録する。
- 中心基準のスケールで位置補正が発生する場合は、移動とスケールを1つのtransactionとして記録する。
