# オブジェクト一覧ウィンドウ仕様

## 1. 対象
- 名称: `Panel_Catalog`
- 実装方式: uGUI（Canvas/Prefab）
- 正となるアセット: `Assets/UI/Prefabs/UIRoot.prefab`

## 2. 目的
- 配置可能オブジェクト一覧を表示し、選択した `typeId` を配置モードへ渡す。
- 画面左側の常設操作パネルとして、ノード追加ウィンドウと隙間なく接続する。

## 3. レイアウト
- アンカー:
  - `anchorMin = (0, 0)`
  - `anchorMax = (0, 1)`
- オフセット:
  - `offsetMin = (0, 0)`
  - `offsetMax = (312, 0)`（初期幅 312）
- 画面に対して上端・下端まで伸長する。
- 右端に横リサイズハンドル `ResizeHandleX` を持つ。

## 4. UI階層（Prefab）
- `Panel_Catalog`
- `Scroll_Catalog`
- `Scroll_Catalog/Viewport`
- `Scroll_Catalog/Viewport/Content`
- `Btn_Template`（非表示テンプレート）
- `ResizeHandleX`

## 5. 見た目
- 背景色: `DesignTokens.BgPrimary`
- カード背景: `DesignTokens.Surface` + `DesignTokens.Divider` の細線
- カード内表示:
  - カテゴリバッジ（例: `車両`, `工具`, `環境`, `追加`, `その他`）
  - 表示名（例: `車両`, `工具箱`, `タイヤ交換`）
  - 技術ID（例: `Vehicle/Car_Proxy`）
- 文字色: `DesignTokens.TextPrimary` / `DesignTokens.TextSecondary`

## 6. 挙動
- `CatalogUI` が `PrefabRegistry.entries` を列挙し、`Btn_Template` を `Content` に生成。
- 各カードはカテゴリ、表示名、技術IDを表示し、左揃えで配置する。
- ボタン押下で `onSelectType(string typeId)` を発火。
- カード押下後、ワールドクリック待ちの配置モード中は該当カードをテーマ青（`DesignTokens.Accent`）の枠線で強調表示する。
- 実行時の機能接続:
  - `PlacementController` が見つかる場合、`CatalogUI` は `registry` を自動バインド。
  - 永続イベント未設定時は `PlacementController.EnterPlacement` をランタイム接続。

## 7. リサイズ
- スクリプト: `PanelHorizontalResizeHandle`
- 操作: `ResizeHandleX` を左右ドラッグ
- 制約:
  - `minWidth = 240`
  - `maxWidth = 420`
- 幅変更時、`UiPanelDockSync` によりノード追加ウィンドウの左端が追従し、隙間は常に `0`。

## 8. 依存スクリプト
- `CatalogUI`
- `PanelHorizontalResizeHandle`
- `UiPanelDockSync`

## 9. 変更ルール
- 見た目調整は `UIRoot.prefab` 側で行う。
- 機能変更（イベント配線/データソース）は `CatalogUI` 側で行う。

## 13. 追記（2026-03-02 / カード削除ボタン）
- 各オブジェクトカードに小型の `×` ボタン（`Button_RemoveCard`）を追加。
- `×` はカードホバー時のみ表示する。
- `×` はカード右上角の外側にはみ出す配置とし、丸の中心がカード角に重なる。
- `×` ボタン背景は完全な丸形とする。
- `×` 押下時、該当 `typeId` のカードをオブジェクト一覧から除去する。
- 本挙動は「一覧からの除去」のみを対象とし、ワールド内に既に配置済みのオブジェクトには影響しない。
- 除去済みカードは、検索フィルタ変更や `RebuildCards()` 実行後も同一セッション内では復活しない。
- `BuildUiPrefabs` の `Card_Template` に同ボタンを追加し、既存Prefab向けには `CatalogUI` がランタイム補完する。

## 配置済み一覧の整列メニュー

- 「一覧」の検索欄・操作バーの下に`> 整列メニュー`を表示し、初期状態は閉じる。
- 展開時は`v 整列メニュー`とX/Y/Z整列・等間隔の2行を表示する。上下行と一覧との間隔は8px、トグル内の左右余白は16pxとする。
- 閉じると一覧の上端を96px引き上げる。整列は2個以上、等間隔は3個以上で有効化する。
- 複数選択と基準に関する常設説明は表示しない。折畳み状態は表示中のみ保持し、教材には保存しない。

## 複数対象の選択

- 3Dビューの空白からドラッグすると、塗りのない青い点線の外枠（2pxの点・2pxの間隔）と表示領域が少しでも重なる対象を選択する。Shiftを押して開始すると既存選択へ追加する。
- 枠選択は6px以上の移動で開始する。Esc、UI領域／Game view外への移動、視点ドラッグで中止し、開始前の選択を維持する。
- 3Dビューにポインターがあるとき、Ctrl/Cmd+Aで全選択、Escで解除する。文字入力中・配置待ち・対象ピペット中は無効。
- 一覧で通常クリックした行を起点に、Shiftクリックで検索結果内の連続範囲を選択する。Ctrl/Cmd+Shiftでは範囲を追加し、Ctrl/Cmdクリックでは個別の追加／解除とする。
- 非表示・固定中の対象は編集選択から除外する。親と子は同時に選択しない。枠選択の候補では子を優先し、全選択・一覧の集合選択では親を優先する。
- Fとカメラメニューの「選択へ」は選択集合の全体を表示する。選択範囲がカメラの距離／サイズ上限を超える場合は上限に従う。
- 操作ヒントに範囲選択、全選択、解除の説明を掲載する。ヒントパネルは600×540とし、常設説明は増やさない。

## 一覧の親子表示

- 一覧は行間0px・高さ28pxの連続したツリー表示とする。交互の行背景と選択行の帯を使い、角丸カードや下段の説明は表示しない。グループは三角の開閉ボタン・種別記号・太字で示す。
- 子部品は1階層16px（最大6段）の字下げと接続線で表示する。名称は1行で省略表示し、子のない行も開閉ボタン分の空間を確保して同階層の名称を揃える。
- 表示だけを変更し、モデルの親子構造と保存データは変更しない。

## 配置物のコピー・貼り付け

- ポインターを3Dビュー上に置き、Ctrl/Cmd+Cで選択対象をコピー、Ctrl/Cmd+Vで貼り付ける。複数選択を保持し、貼り付け先を選択する。
- 通常貼り付けはコピー時点からX/Z各0.2ずつずらし、繰り返すごとにずらす幅を増やす。Ctrl/Cmd+Shift+Vはコピー時の位置へ貼り付ける。
- コピー時の位置・向き・スケール・名前・説明・子部品状態を保持する。元対象の編集や削除に影響されない。クリップボードは実行中だけ保持し、OSの文字クリップボードは変更しない。
- 新IDを割り当て、既存の条件参照は元対象に残す。一回の貼り付けを一つのUndo/Redoへ記録する。
- コピー／貼り付けの件数と失敗を上部ステータスに表示する。素材が見つからない場合や構造不一致の場合は全件中止する。
- グループ行の左の開閉ボタンで子孫を折り畳む。初期状態は展開、入れ子は個別に開閉でき、親を閉じても子グループの開閉状態は保持する。折畳みは一覧だけに作用し、3D表示・選択・教材データは変えない。
- 検索中は一致する子を折畳みに関係なく表示し、開閉ボタンを無効化する。検索解除後は元の開閉状態へ戻す。Shift範囲選択は現在一覧に表示されている行だけを対象とする。
