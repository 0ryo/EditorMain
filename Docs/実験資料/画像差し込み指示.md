# 操作ガイド・課題シートへのスクリーンショット差し込み指示

この文書は、Unity を起動できる環境の Claude への作業指示です。上から順に実行してください。ここに書いた値（サイズ・比率・色・位置）はすべて確定済みです。この文書の範囲で判断できることは、利用者に質問せずに進めてください。

## 0. 目的と完成の条件

`Docs/実験資料/操作ガイド.html`（A4・6ページ）と `Docs/実験資料/課題シート.html`（A4・3ページ）には、写真枠が15か所あります（S01〜S13、T01〜T02）。いまは斜線の下書き枠が表示されています。この15枠に、Unity エディタ（教材作成ツール）の実際の画面を撮影して入れ、PDFを作り直します。

完成の条件は次の4つです。

1. `Docs/実験資料/images/` に15枚の PNG があり、ファイル名・比率・ピクセル数が「3. 撮影一覧」と一致している。
2. HTML をブラウザで開くと15枠すべてに写真が入り、画面下の「撮影リスト」の状態欄がすべて「入れ済み」になっている。
3. 番号ピン（S01・S04・S06・S10）が、指している UI 部品の上に正しく乗っている。
4. `操作ガイド.pdf` と `課題シート.pdf` を作り直し、ページ数が6ページと3ページのまま変わっていない。

## 1. 変えてはいけないもの

- HTML の本文の文章、レイアウト用の CSS、`<script>` は変えない。編集してよいのは、番号ピンの `style="--x:…;--y:…"` の値だけです。
- 写真が入る仕組みは既存の `<script>` が持っています。`images/<ID>.png` が存在すれば、枠は自動で写真に置き換わります。`<img>` タグを手で書き足さないでください。
- 操作ガイドに書かれたボタン名や欄名が実際の画面と違っていても、HTML の文章は直さないでください。違いは最後の報告に一覧で書いてください。
- Unity のシーン・プレハブ・サンプル教材（`Assets/StreamingAssets/Samples/TireChange/` など）を、撮影のために上書き保存しない。撮影用に変えた状態は保存せずに破棄するか、見本のコピーに対して操作する。
- 撮影用の補助スクリプトは、リポジトリの外（作業用の一時フォルダー）に置く。リポジトリに新しい依存を追加しない。

## 2. 画像の共通仕様

### 2.1 形式と置き場所
- 形式は PNG（24bit、不透明）。透過を残さない。
- 置き場所は `Docs/実験資料/images/`。ファイル名は `S01.png` のように、ID と小文字の `.png` にする。

### 2.2 比率とピクセル数
- HTML の写真枠は、`object-fit: cover; object-position: top left` で画像を表示します。比率が違うと、画像の右端か下端が黙って切り落とされます。比率は「3. 撮影一覧」の値に**完全に**合わせてください。
- 最終のピクセル数は、印刷時に 300dpi になる値です（「3. 撮影一覧」の「保存サイズ」）。必ずこのサイズで保存してください。
- 拡大は禁止です。切り抜いた範囲が保存サイズより小さくなる場合は、撮影の解像度を上げて撮り直してください（2.3 の superSize を 3 にする）。縮小は Lanczos などの高品質な方法で行う。

### 2.3 撮影の解像度（Unity）
- Game ビューの解像度を **1920×1200（16:10）の固定解像度** にする。全画面の写真（S01・S06・S10）の比率16:10と一致させるためです。
- 撮影は `ScreenCapture.CaptureScreenshot(path, 2)` を使い、3840×2400 の画像を得る。UI が2倍の解像度で描かれるので、切り抜いても文字がぼけません。
- 切り抜き写真（S02〜S05、S07〜S09、S11、S12、T01、T02）は、この 3840×2400 の画像から切り抜く。
- 撮影のたびに、マウスカーソル・ツールチップ・選択中のハイライトが写り込んでいないか確認する。ツールチップは、撮影前にマウスを UI 部品のない場所へ移して消す。ただし、写真の内容としてホバーや選択の状態が必要な場合は除く（「3. 撮影一覧」に書いてある場合だけ）。

### 2.4 角丸・枠線・影
- **画像そのものに角丸を付けない。** 四隅は直角のまま保存する。角丸は HTML 側で付きます（`border-radius: 2.6mm`、はみ出しは `overflow: hidden` で隠れる）。画像側で丸めると二重に丸まり、角に背景色が見えます。
- 枠線・ドロップシャドウ・余白を画像に足さない。HTML 側で 1px の枠線（`#CDD5E0`）が付きます。
- macOS のウインドウ撮影で付く影を入れない（S13 は 3.4 を参照）。

### 2.5 書き込み（注記）
注記を描き込むのは T02 の丸だけです。ほかの写真には矢印・文字・丸を描き込まないでください。番号は HTML のピンで付けます。

## 4. 撮影の前準備

1. `origin/main` の最新を取り込み、Unity でプロジェクトを開く。
2. 見本教材「タイヤ交換（見本）」（`Assets/StreamingAssets/Samples/TireChange/sample.json`、14手順）を、ツールの通常の手順で開く。見本はコピーが作られて開くので、元の見本は変わりません。S01〜S12 は、このコピーで撮影します。
3. Game ビューを 1920×1200 の固定解像度にし、Scale を 1x にする。
4. 撮影前に、ウインドウ内に開いたままのダイアログやメニューがないことを確認する。

- 状態：T01 と同じ配置で、左前輪に近づく。ホイールのナットがはっきり数えられる大きさにする（ホイールの直径が写真の高さの 60〜80%）。正面から少し前寄りに見て、「上・前側」のナットが分かる角度にする。

  - 線の太さ：保存サイズ（1064×665）で 8px。保存サイズに縮小した後で描く。
  - 文字や矢印は付けない。

## 6. 番号ピンの位置合わせ

ピンは HTML の `<span class="pin" style="--x:48%;--y:4.4%">1</span>` で描かれています。`--x` と `--y` は、写真の左上を 0%・右下を 100% としたときのピンの中心です。写真を入れた後、次の規則で値を書き換えてください。

- 欄・領域（左の欄、3D画面、右の欄、手順一覧、条件の一覧など）を指すピンは、その領域の中で文字のない余白に置く。領域の左右中央を第一候補にし、文字にかかる場合は上下にずらす。
- ボタン・ボタンの列を指すピンは、ボタンの文字を隠さないように、ボタンの左上の角にピンの中心を合わせる。左上が別の UI にかかる場合は右上の角にする。
- ピンの直径は写真の幅の約 4.6%（S01・S06・S10）、約 11.5%（S04）です。ピンがほかの写真の文字や別のピンに重ならないようにする。
- 値は小数第1位までの % で書く（例：`--x:47.5%;--y:4.0%`）。

## 7. 確認と PDF の作り直し

### 7.1 表示の確認
1. `操作ガイド.html` と `課題シート.html` を Chrome で開き、15枠すべてに写真が入っていることと、ページの下の「撮影リスト」がすべて「入れ済み」になっていることを確認する。
2. ページごとにスクリーンショットを撮り、次を目で確認する。
   - 写真の右端・下端が切れていない（比率が合っている）。
   - 写真の角が二重に丸まっていない。角に白や黒の三角が見えない。
   - ピンが 6 の規則どおりに乗っている。
   - 写真の中の文字が読める。ぼけていない。

### 7.2 PDF の作り直し
PDF は A4・余白なし・背景を印刷する設定で、Chromium の印刷機能から出力します。Playwright を一時フォルダーに入れて、次のスクリプトを実行してください（リポジトリには入れない）。

```js
// export.js  使い方: node export.js <HTMLの絶対パス> <PDFの絶対パス>
const { chromium } = require('playwright');
(async () => {
  const [, , html, pdf] = process.argv;
  const browser = await chromium.launch();
  const page = await browser.newPage();
  await page.goto('file://' + html);
  await page.evaluate(() => document.fonts.ready);
  // 写真の読み込みを待つ
  await page.waitForFunction(() => [...document.querySelectorAll('.shot[data-id]')].every(e => e.classList.contains('has-img')), null, { timeout: 15000 });
  await page.emulateMedia({ media: 'print' });
  await page.pdf({ path: pdf, preferCSSPageSize: true, printBackground: true });
  await browser.close();
})();
```

- `waitForFunction` がタイムアウトした場合は、どれかの画像が読み込めていません。ファイル名と置き場所を確認してください。
- 出力先は `Docs/実験資料/操作ガイド.pdf` と `Docs/実験資料/課題シート.pdf`（上書き）。
- 出力後、ページ数が操作ガイド6ページ・課題シート3ページであること、各ページが A4（595×842pt）であることを確認する。
