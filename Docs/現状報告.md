## 1. MVP-4のゴール（何がどう動けば完了か）

MVP-4仕様書（`Docs/MVP-4.md`）を基準にすると、完了条件は次の2層に分かれます。

### 1.1 EditorMain（このリポジトリ側）での完了条件
- 指導者がノードUIで `Start -> Step... -> End` の**線形手順**を作れる
- 各Stepに `Condition`（A/B選択、SnapHold）を **1〜3個（AND）** で紐付けできる
- 接続制約（分岐禁止、循環禁止、Condition接続制約など）を編集時に守れる
- E-01〜E-11の検証で不正時はエクスポート不可、警告W-01/W-02は表示される
- JSONが `version=2`、`scenarioSettings`、`requiredActions[].conditions[]` を含んで出力される
- 参照切れ（削除オブジェクト）は未設定化され、E-08/E-10で保存不可になる

### 1.2 MVP-4仕様全体（Quest側契約を含む）での完了条件
- Quest側で `SnapHold(1.0s)` 判定によりCondition達成を判定できる
- 全Condition達成でStepが自動進行し、巻き戻しなしで進む
- Quest側UIで現在Stepの条件文を全行表示できる
