# UI デザイン仕様書

> Version: 1.0  
> 作成日: 2026-02-22  
> 対象: Unity uGUI (Canvas + TextMeshPro)  
> 用途: **AIエージェントへのデザイン指示書** — この文書の指定に厳密に従うこと

---

## 0. AI向け指示

```
あなたはこのデザイン仕様書に従ってUIを実装するエンジニアです。
以下のルールを厳守してください。

1. この仕様書に定義された値だけを使え。独自の判断で色・サイズ・余白を変更するな
2. 「おそらくこの方が良い」という改善を勝手にするな。仕様にないものは追加するな
3. 余白は多い方が正しい。迷ったら広く取れ
4. 要素を追加する前に「これは本当に必要か？」と自問し、不要なら追加するな
5. フォントウェイトは2種類（Regular/SemiBold）のみ。Bold, Light等は使うな
6. 装飾的な影、光沢、テクスチャ、グラデーションは禁止
7. 角丸は全て統一値。要素ごとに変えるな
8. Pure Black (#000000) と Pure White (#FFFFFF) は使うな
```

## 1. デザイン哲学

このプロジェクトのUIは以下の原則に従う。判断に迷ったらここに戻れ。

| 原則 | 説明 | 実践 |
|---|---|---|
| **Less is More** | 余計な要素は全て削ぎ落とす | 「これを削除しても機能するか？」→ するなら削除 |
| **空の力** | 余白はデザインの主役 | 要素を詰め込まず、呼吸する空間を確保 |
| **正直なデザイン** | 装飾で誤魔化さない | 影・光沢・グラデーション禁止。素材そのまま |
| **機能 = 形** | 全要素に役割がある | 飾りだけの要素は即削除 |
| **一貫性** | 全画面で同じルール | 画面ごとに独自スタイルを作らない |
| **ユーザー中心** | 認知負荷の最小化 | 1画面1コンセプト。Progressive Disclosure |

## 2. カラーシステム

### 2.1 パレット定義

Pure Black / Pure White は使用禁止。すべてオフトーンで柔らかさを出す。

| トークン名 | Hex | Unity Color (RGBA 0-1) | 用途 |
|---|---|---|---|
| `bg-primary` | `#F7F7F8` | `(0.969, 0.969, 0.973, 1.0)` | メイン背景 |
| `bg-secondary` | `#EDEDF0` | `(0.929, 0.929, 0.941, 1.0)` | カード・パネル背景 |
| `bg-tertiary` | `#E2E2E7` | `(0.886, 0.886, 0.906, 1.0)` | 区切り線・セパレータ |
| `surface` | `#FFFFFF` | `(1.0, 1.0, 1.0, 1.0)` | 浮いたカード表面 ※例外的にPure White可 |
| `text-primary` | `#1D1D1F` | `(0.114, 0.114, 0.122, 1.0)` | メインテキスト |
| `text-secondary` | `#6E6E73` | `(0.431, 0.431, 0.451, 1.0)` | 補助テキスト・ラベル |
| `text-tertiary` | `#AEAEB2` | `(0.682, 0.682, 0.698, 1.0)` | プレースホルダー・無効テキスト |
| `accent` | `#0A84FF` | `(0.039, 0.518, 1.0, 1.0)` | プライマリアクション・リンク・選択状態 |
| `accent-hover` | `#0070E0` | `(0.0, 0.439, 0.878, 1.0)` | accent の hover/press 状態 |
| `success` | `#30D158` | `(0.188, 0.820, 0.345, 1.0)` | 成功・保存完了 |
| `warning` | `#FF9F0A` | `(1.0, 0.624, 0.039, 1.0)` | 警告・注意 |
| `error` | `#FF453A` | `(1.0, 0.271, 0.227, 1.0)` | エラー・削除 |
| `divider` | `#D1D1D6` | `(0.820, 0.820, 0.839, 1.0)` | 細い区切り線 |

### 2.2 カラールール

- **ベース: ニュートラル（グレー系）のみ。** 面積の90%以上はニュートラルカラー
- **アクセント: 1色のみ (`accent`)。** 意味のある場所だけに使用
- **セマンティックカラー:** 色は意味を持つ。装飾としての色使い禁止
  - 青 = アクション / 選択
  - 緑 = 成功
  - 黄 = 警告
  - 赤 = エラー / 削除
- **コントラスト:** テキストは背景に対して WCAG AA (4.5:1) 以上
- **モノクロテスト:** 色を全てグレースケールにしても機能的に成立すること

## 3. タイポグラフィ

### 3.1 フォント

| 用途 | フォント | Fallback |
|---|---|---|
| 全テキスト | **Noto Sans JP** | sans-serif |

> フォントファミリーは **1つだけ**。2つ目のフォントは使用禁止。

### 3.2 Type Scale

8pt ベースラインに従う。

| レベル | fontSize | fontWeight | lineHeight比 | 用途 |
|---|---|---|---|---|
| `display` | 32 | SemiBold (600) | 1.3 | 画面タイトル（使用箇所は極限定） |
| `heading` | 20 | SemiBold (600) | 1.4 | セクション見出し |
| `subheading` | 16 | SemiBold (600) | 1.4 | カードタイトル・ラベル |
| `body` | 14 | Regular (400) | 1.6 | 本文・説明テキスト |
| `caption` | 12 | Regular (400) | 1.5 | 補助情報・タイムスタンプ |
| `micro` | 10 | Regular (400) | 1.4 | バッジ・極小ラベル |

### 3.3 タイポグラフィルール

- **ウェイトは2種類のみ:** Regular (400) と SemiBold (600)
- **長文は左揃え。** 中央揃えは短いタイトルかラベル限定
- **文字間隔 (letterSpacing):** 0（デフォルト）。調整禁止
- **全角英数は禁止。** 英数字は必ず半角
- TextMeshPro の `SDF Font Asset` を使用。ランタイムフォント禁止

## 4. スペーシングシステム

### 4.1 基本単位: 4px

全ての余白・パディング・マージンは **4の倍数** で統一。

| トークン | 値 | 主な用途 |
|---|---|---|
| `space-none` | 0 | 密着 |
| `space-xs` | 4 | アイコンとラベルの間 |
| `space-sm` | 8 | 関連要素間（同グループ内） |
| `space-md` | 16 | カード内パディング・要素間の標準ギャップ |
| `space-lg` | 24 | セクション内の区切り |
| `space-xl` | 32 | セクション間 |
| `space-2xl` | 48 | 大セクション間・画面上下余白 |

### 4.2 スペーシングルール

- **迷ったら広い方を選べ。** 余白が多い = 正解
- **Gestalt の近接則:** 関連するものは近く、無関連は遠く
- 同グループ内の要素間: `space-sm` (8)
- 異なるグループ間: `space-lg` (24) 以上
- パネル内パディング: 最低 `space-md` (16)

## 5. レイアウト

### 5.1 構造原則

- **1画面1コンセプト。** 複数の無関連な機能を1画面に詰め込まない
- **Visual Hierarchy を明確に。** サイズ・色・位置で重要度を表現
- **1画面にプライマリアクションは1つ。** 目立つボタンは1つだけ
- **Progressive Disclosure:** 必要な情報だけ最初に見せ、詳細は展開/hover で

### 5.2 グリッドとアライメント

- **左揃え基本。** 全要素は左端を基準に整列
- **Pixel-perfect:** 全要素がグリッドに吸着。2px以上のズレは禁止
- Unity uGUI: `VerticalLayoutGroup` / `HorizontalLayoutGroup` で構成
  - `childForceExpandWidth = false`
  - `childForceExpandHeight = false`
  - `childControlWidth = true`
  - `childControlHeight = true`

### 5.3 Canvas Scaler

```
UI Scale Mode: Scale With Screen Size
Reference Resolution: 1920 x 1080
Screen Match Mode: Match Width Or Height
Match: 0.5
```

## 8. インタラクション

### 8.1 状態表現

| 状態 | 表現方法 |
|---|---|
| Default | 通常表示 |
| Hover | 背景色を1段階暗く。色変化は `transition-duration` でスムーズに |
| Press | 背景色をさらに1段階暗く |
| Focus | 2px `accent` border |
| Disabled | opacity 0.4。クリック不可 |
| Selected | `accent` 色のインジケータ（左ボーダー or 背景淡色） |
| Error | `error` 色のボーダー + エラーメッセージ `caption` サイズ |

### 8.2 アニメーション

- **控えめで自然なものだけ。** 過剰アニメーション禁止
- **許可するもの:**
  - Hover/Press の背景色フェード (150ms ease)
  - パネルの開閉 (200ms ease-out)
  - ステータスメッセージのフェードイン/アウト (200ms)
- **禁止するもの:**
  - バウンスアニメーション
  - 回転アニメーション
  - パーティクルエフェクト
  - スケールアニメーション（ボタンが大きくなる等）
  - 300ms以上のアニメーション

## 10. 禁止事項チェックリスト

UI実装後、以下をすべて確認すること。1つでも該当したら修正。

- [ ] Pure Black (#000000) が使われていないか
- [ ] Pure White (#FFFFFF) が背景に使われていないか（surfaceカード以外）
- [ ] 3種類以上のフォントウェイトが使われていないか
- [ ] 装飾的な影（ドロップシャドウ）が使われていないか
- [ ] グラデーションが使われていないか
- [ ] アクセントカラーが2色以上使われていないか
- [ ] 角丸が要素ごとにバラバラになっていないか
- [ ] 4の倍数でない余白が使われていないか
- [ ] 意味のない装飾要素がないか
- [ ] 1画面に2つ以上のプライマリアクションボタンがないか
- [ ] 中央揃えの長文がないか
- [ ] テキストの背景コントラストが4.5:1未満でないか
- [ ] 300ms以上のアニメーションがないか
- [ ] fillアイコンとstrokeアイコンが混在していないか
- [ ] フォントサイズがType Scaleに定義されていない値でないか
